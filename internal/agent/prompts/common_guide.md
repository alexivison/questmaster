The questmaster CLI is available in this shell; run questmaster help (or questmaster <command> --help) for commands and flags. Use questmaster list for a session overview and questmaster read <session-id> to inspect a session.
Send messages with questmaster send <session-id> "message"; workers use questmaster send master to report, and masters use questmaster send all to broadcast.
OpenCode message targets must be idle or done; a blocking wait loop keeps the target working and makes send fail.
The session that opens or is handed a PR runs questmaster pr watch <url> right away, then ends its turn or moves to other work; a master does not also watch a PR its worker owns. Alerts start [PR owner/repo#N] and reach the watcher only while idle or done. On an alert, read questmaster pr events <ref> --unread and act. Repeating pr watch is safe. A watch ends when its session is deleted or pruned.
Wait for CI, reviews and comments through these alerts, not your own polling: no gh pr checks --watch, gh run watch, sleep loops, Claude Monitor, background waits, ScheduleWakeup or Codex watch loops, which also hold alerts back. A one-off gh pr view or gh pr checks for the current state is fine.
