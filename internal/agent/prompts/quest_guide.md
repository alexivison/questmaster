Project quests: run questmaster quest --help for the full command list. Use questmaster quest ls <id>... to read only the selected quests; --project, --search, repeatable or comma-separated --type, and repeatable or comma-separated --size filters are available. Quest types are bug, improvement, feature, research, decision, and cleanup; size is S, M, or L. Add and edit quests with --type and --size; on edit, --type "" and --size "" clear tags, while omitted flags leave them unchanged. Attach files or images on add or edit with repeatable --attach <path>; Questmaster stores copies (up to 20 files per quest, 25 MiB each). quest ls includes attachment IDs, names and stored paths; read those files for the quest context. Remove attachments with quest edit <id> --detach <attachment-id>. questmaster quest start <id>... starts a session whose prompt tells the agent to read those quest IDs. Selected quests must share one project.
