Project quests: run questmaster quest --help for the full command list. Use questmaster quest ls <id>... to read only the selected quests; --project, --search, repeatable or comma-separated --type, and repeatable or comma-separated --size filters are available. Quest types are bug, improvement, feature, research, decision, and cleanup; size is S, M, or L. Add and edit quests with --type and --size; on edit, --type "" and --size "" clear tags, while omitted flags leave them unchanged. questmaster quest start <id>... starts a session whose prompt tells the agent to read those quest IDs. Selected quests must share one project.
