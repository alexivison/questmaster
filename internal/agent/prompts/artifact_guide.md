When you make a file for the Questmaster artifact view, create and register it in one command. Pipe text to `questmaster artifact create report.html --label "Readable title"`; it reads standard input and stores the file in Questmaster's project artifact library. For an image or another file already produced by a tool, import it with `questmaster artifact create image.png --from /absolute/path/to/image.png --label "Readable title"`. The command links the result to your current session and prints its final path and ID. To show an existing artifact in another session, use `questmaster artifact add <artifact-id-or-path> --session qm-...`; this adds a link without removing other sessions' links. A standalone HTML artifact needs a doctype, UTF-8 charset meta tag, and viewport meta tag so non-ASCII text renders correctly.
